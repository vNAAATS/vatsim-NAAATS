# vNAAATS V2.0

The Gander Oceanic (CZQO) EuroScope plugin and live web Flight Data Display, revived from Andrew Ogden's original vNAAATS with his permission.

## What is in it
- **Flight Data Display** at https://vnaaats.com/fdd: flights grouped by NAT track, edit level, Mach and track, SELCAL, notes, aircraft menu, natTrak clearance requests, Auto RCL and CPDLC. Works on tablets and installs as an app.
- **Concorde:** the four historic tracks SM, SN, SO and SP, block level, voice position reports and overdue alerts.
- **EuroScope plugin:** tracking, handoffs and transfers from the web display, re-tracking after a crash, conflict probe, natTrak and CPDLC integration.
- **Sign-in and data protection:** the display is covered until you sign in with a position; there is no view-only mode. Certified oceanic controllers get a personal key and password from https://ganderoceanic.ca/my/vnaaats.

## Update
Close EuroScope and replace **only** `VatsimNAAATS.dll` (keep your `vnaaats.cfg`). First time? https://vnaaats.com/guide

## Files
- `VatsimNAAATS.dll` - the plugin
- `VatsimNAAATS-plugin.zip` - plugin, readme, example config and radar screen file
- `vnaaats-server.tar.gz` - server and built display (for whoever runs the server)
